# NiceLIMS | Sistema de Gestión de Laboratorios 

Aplicación web minimalista para la gestión, inventario y mantenimiento de laboratorios universitarios. Diseñado para ser rápido, eficiente y fácil de usar.

## Ejecutar localmente

**Prerrequisitos:**  Node.js

1. Instala dependencias:
   `npm install` o `npm i`
2. Ejecuta la app:
   `npm run dev`
